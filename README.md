# О подарках

Русский editorial-лонгрид «Почему выбрать подарок так сложно, даже когда купить можно всё».

## Просмотр

[Открыть сайт](https://senatorkhan.github.io/gift-longread/).

`index.html` — автономная страница: CSS, JavaScript, изображения и шрифты встроены в файл. Установка зависимостей и сборка не требуются.

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll.

## Материалы

- Шрифты: Prata и Golos Text, SIL Open Font License 1.1. Полные уведомления и лицензия: [FONT-LICENSES.txt](FONT-LICENSES.txt).
- Предметные фотографии: Cup of Couple и Bedia / Pexels. Ссылки на оригиналы сохранены в подписях на странице; применяется [лицензия Pexels](https://www.pexels.com/license/).
- Три сцены с людьми созданы с помощью ИИ. Все персонажи вымышлены; изображения не показывают участников исследования. Это отмечено на странице.
- Источник данных указан в разделе «Источники». Респонденты могли выбирать несколько вариантов ответа.

Для обновления сайта замените `index.html` и сохраните изменения в `main`. Исходники предыдущих итераций и рабочие материалы в этот репозиторий не включены.
