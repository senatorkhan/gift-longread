# Именно — о подарках

Русский editorial-лонгрид «Почему выбрать подарок так сложно, даже когда купить можно всё».

Айдентика «Именно»: оригинальный векторный логотип с лентой «м», тёплый айвори, шоколадный текст и бордовые акценты. Лонгрид остаётся самостоятельной редакционной страницей; текст, данные и пара Prata / Golos Text сохранены.

Итерация v4: единая пятиколоночная основа и центральная колонка чтения, упорядоченные отступы, шоколадные разделители, более компактный первый экран и реальные фотографии. Полоски статистики появляются при прокрутке; проценты всегда видны. При отключённом JavaScript или предпочтении reduced motion содержимое доступно без анимации.

## Просмотр

[Открыть сайт](https://senatorkhan.github.io/gift-longread/).

`index.html` — автономная страница: CSS, JavaScript, изображения и шрифты встроены в файл. Установка зависимостей и сборка не требуются.

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll.
